# Static Linux

**Página del proyecto:** [staticforge.me/linux](https://staticforge.me/linux/)

Distribución basada en Arch de [Static Forge](https://staticforge.me). *fast. private. yours.*

El código está todavía en un repositorio privado mientras se cierra la fase 3 (instalador y
primer arranque ya funcionan end-to-end en QEMU y en hardware real). Aquí se publicará cuando
la ISO esté lista para que la instale cualquiera.

Para hablar del proyecto: [el foro del estudio](https://staticforge.me/foros.html) o el
[Discord](https://discord.gg/bVdwvtnbuH).
