# Static Linux
**by Static Forge**

> Fast. Private. Yours.

Arch-based Linux distribution with automatic hardware detection,
adaptive desktop environments, and privacy-first defaults.

## Architecture
- Base: Arch Linux
- Installer: Calamares + sl-detect
- Environments: Hyprland+Astal / XFCE / Openbox
- Privacy: 3 configurable profiles
- Filesystems: BTRFS (default) / EXT4 / XFS / F2FS / ZFS
- Boot: GRUB / systemd-boot / Limine / rEFInd
