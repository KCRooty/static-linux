# Mascota: Sae

Static Linux tiene mascota: **Sae**, una serpiente morada.

`sae-boceto.png` es el boceto original de Core, dibujado con **Paint It!**
(`laboratorio/paint-it/` en la web) — morado sobre un poste marrón, lengua
roja bífida. Es punto de partida, no arte final: el diseño de verdad (vector,
variantes de pose, tamaños para favicon/wallpaper/sl-welcome) lo hace Core.

Encaja con la paleta morada ya existente en la marca (el morado de Shadow en
DONNIES, `#7B61FF`) — a decidir si Sae usa ese mismo morado o uno propio.

Pendiente de decidir: dónde aparece (favicon, sl-welcome, GRUB/Plymouth,
página de descarga, merch) y si lleva variantes por tema (8 temas, 3
estilos).
